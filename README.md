# RockWire 🤘 — تجمیع‌کننده‌ی اخبار راک و متال

یک وب‌اپلیکیشن خبری که اخبار موسیقی راک و متال را به‌صورت زنده از فیدهای RSS دو رسانه‌ی **Loudwire** و **Loudersound** می‌گیرد، در یک‌جا نمایش می‌دهد و یک پنل مدیریت ساده هم برای افزودن، ویرایش و حذف خبر دارد.

## امکانات

**برای کاربر**
- نمایش اخبار به‌صورت کارت (تصویر، عنوان، خلاصه، دسته‌بندی، منبع و تاریخ)
- جستجوی کلیدواژه‌ای با debounce (۴۰۰ میلی‌ثانیه)
- فیلتر دسته‌بندی (Metal، Classic Rock، Prog، تور و فستیوال، بررسی آلبوم) و فیلتر منبع
- صفحه‌بندی، با هماهنگی کامل جستجو، فیلترها و شماره‌ی صفحه با آدرس (`?q=&cat=&src=&page=`)
- صفحه‌ی جزئیات با SEO پویا (title، description و تصویر Open Graph برای هر خبر) و ۳ خبر مرتبط
- بوکمارک و ذخیره‌ی آن در مرورگر
- تم تیره و روشن
- Skeleton Loading، Toast، و حالت‌های خالی و خطا

**برای ادمین** (مسیر `/admin`)
- جدول اخبار با عنوان، دسته‌بندی، تاریخ و وضعیت (منتشر شده / پیش‌نویس)
- ساخت، ویرایش و حذف خبر (حتی اخبار آمده از RSS)
- مسیر `/admin` بدون ورود به `/login` هدایت می‌شود

## تکنولوژی‌ها

| بخش | ابزار |
|---|---|
| فریم‌ورک | Next.js 14 (App Router) + React 18 + TypeScript |
| مدیریت state | Redux Toolkit (auth، bookmarks، theme) |
| دریافت داده | TanStack Query v5 (`useQuery` / `useMutation`) |
| استایل | Tailwind CSS + فونت Vazirmatn (راست‌چین) |
| RSS | `rss-parser` |
| پروکسی (اختیاری) | `undici` |

## اجرا

نیازمندی: Node.js نسخه‌ی ۱۸ یا بالاتر.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start   # حالت production
```

**ورود به پنل ادمین:** هر ایمیل معتبر و رمزی با حداقل ۴ حرف.

## نحوه‌ی کار

1. مرورگر از `/api/news` خبر می‌خواهد (با پارامترهای `q`، `cat`، `src`، `page`).
2. سرور فیدها را می‌گیرد (با User-Agent مرورگر و مهلت ۸ ثانیه)، هر خبر را به یک قالب یکسان تبدیل می‌کند و ۵ دقیقه کش می‌کند.
   - تصویر از `media:content`، `media:thumbnail`، `enclosure` یا اولین `<img>` متن برداشته می‌شود.
   - دسته‌بندی با کلیدواژه حدس زده می‌شود (مثلاً «review» یعنی بررسی آلبوم). این روش تقریبی است.
3. اخبار RSS با اخبار ادمین ترکیب می‌شوند، ویرایش‌ها و حذف‌های ادمین اعمال می‌شود، و سپس فیلتر، جستجو و صفحه‌بندی انجام می‌شود.
4. اگر هیچ فیدی در دسترس نباشد، آخرین اخبار موفق یا اخبار نمونه نمایش داده می‌شود، همراه با هشداری که دلیل خطا را نشان می‌دهد.

صفحه‌ی جزئیات داده را مستقیم در سرور از همین لایه می‌خواند و به API داخلی درخواست نمی‌زند.

### API

| متد و مسیر | توضیح |
|---|---|
| `GET /api/news` | پارامترها: `q`، `cat`، `src`، `page`، `limit`، `admin=1` (با توکن، پیش‌نویس‌ها را هم برمی‌گرداند) |
| `POST /api/news` | ساخت خبر (نیاز به هدر `Authorization: Bearer …`) |
| `GET /api/news/:id` | یک خبر |
| `PUT /api/news/:id` | ویرایش |
| `DELETE /api/news/:id` | حذف |
| `POST /api/login` | بدنه: `{email, password}`؛ خروجی: `{user, token}` |

## عیب‌یابی: اخبار زنده نمی‌آیند

فیلترشکنِ مرورگر روی سرور Next.js (Node) اثری ندارد. اگر هشدار زرد بالای لیست دیدید:

- VPN را روی حالت سراسری یا TUN بگذارید، **یا**
- `.env.example` را به `.env.local` کپی کنید، پورت پروکسی خود را در `HTTPS_PROXY` بنویسید (مثلاً `http://127.0.0.1:10809`) و سرور را دوباره اجرا کنید.

متن خطای هر فید زیر هشدار نوشته می‌شود (مثل `ETIMEDOUT` یا `HTTP 403`). برای دیدن خروجی خام هم می‌توانید `/api/news` را در مرورگر باز کنید.

## محدودیت‌ها

- **ذخیره‌سازی در حافظه است:** تغییرات ادمین با ری‌استارت سرور پاک می‌شود. برای ماندگاری باید دیتابیس اضافه شود.
- **احراز هویت نمایشی است:** توکن ثابت است و هر توکنی را سرور می‌پذیرد. برای استفاده‌ی واقعی نیست.
- **بوکمارک‌ها** و **تم** فقط در localStorage همان مرورگر ذخیره می‌شوند.
- **حقوق محتوا:** اخبار متعلق به Loudwire و Loudersound است. پروژه فقط خلاصه را نشان می‌دهد و لینک خبر اصلی را می‌دهد.
