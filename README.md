ورود: هر ایمیل معتبر + رمز حداقل ۴ حرف. داده‌های ادمین در حافظه سرور است (با ری‌استارت پاک می‌شود).
اگر فیدها در دسترس نباشند، اخبار نمونه و یک هشدار نمایش داده می‌شود. برای عیب‌یابی /api/news را در مرورگر باز کنید.

فیلترشکن: مرورگر شما از VPN استفاده می‌کند ولی سرور Next (Node) جداست.
راه‌حل ۱: VPN را روی حالت سراسری/TUN بگذارید. راه‌حل ۲: .env.example را به .env.local کپی کنید، پورت پروکسی خود را بنویسید و npm install و npm run dev را دوباره اجرا کنید.
